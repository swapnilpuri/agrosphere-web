# Production history

ANL-01 adds a read-only SIMULATED local demonstration screen through the independently pinned Analytics 0.11.0 contract and Gateway. It reads server materialization; it does not sum source collections or infer weather/yield relationships.

Choose an accessible estate, enter Production history, explicitly choose the estate/block and inclusive collection-date range (maximum 367 days), then Read history. Estate selection is explicit after entering the dedicated permission route; no date window is invented. Existing feature permissions remain unchanged. PLATFORM_ADMIN/PLANTATION_ADMIN can read summaries globally; assigned ESTATE_ADMIN/ESTATE_MANAGER/AUDITOR can read their estates. This grants no workforce or unrelated feature access.

The table retains exact decimal kilogram strings. NONE has unknown actual production; pending DRC is unknown dry mass; measured zero remains 0.000. Voids, observed counts, scope-wide version holes/conflicts/unsupported events, source timestamps and capped/truncated highest-version references remain visible. Relative trend positions are illustrative and use exact integer arithmetic; lines break over absence/unknown DRC. JSON counts/versions outside safe browser integer precision fail explicitly rather than display wrong values.

Selection/scope/permission changes cancel requests and clear values. Hidden views pause/cancel; returning refreshes a retained query. Denial/outage never becomes zero or complete data. JWTs remain in memory and attach only to Gateway business routes. No polling, local-storage token/draft persistence, new endpoint, new role or contract modification.

Unit and mocked UI suites cover visibility/cancellation, role boundaries, exact mass and pending/absence/incomplete/outage behavior. Real generated verification is invoked only by Infrastructure scripts/verify_analytics.py with an owned short-lived manifest/marker and transient credentials. It serves a new loopback preview, runs real Keycloak Code/PKCE/Gateway/Analytics, disables traces and removes the listener/fixture. Public-source Docker packaging uses scripts/build-public-image.ps1 and never copies the owner's runtime config. See Architecture ANALYTICS_POC_ADAPTER_VERIFICATION.md for actual results.

The owner-approved finite generated parser profile is defined in Analytics docs/ANL01_ADMISSION_REVIEW.md. Inputs beyond its resource limits receive private ADMISSION_LIMIT diagnosis and contribute no history; these scope-untrusted exclusions cannot be assigned to this block or establish complete coverage. Broader producer activation requires a reviewed transport/streaming design. This screen does not establish complete event coverage, owner M4/M2 acceptance, reference-device performance, REAL/production readiness, offline Android or English/French delivery.
