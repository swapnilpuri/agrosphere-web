# Selected-block environmental readings (TLM-02)

Owner-authorized SIMULATED local POC feature. Architecture's `MQTT_POC_OVERLAY_APPROVAL.md` accepts the immutable review; implementation and owner functional acceptance are separate. The independent `contracts/telemetry.openapi.json` is unchanged Contracts 0.10.0; `telemetry.release.json` records its exact hashes. No sibling source is needed to build Web.

Select a block in Digital twin. The panel reads only the configured Gateway's `/api/v1/telemetry/estates/{estateId}/blocks/{blockId}/latest`, with the existing memory-only session and accepted server role/estate boundaries. It shows exact returned decimal strings, units, observed/received UTC times, rainfall interval, server refresh and SIMULATED provenance. Coverage means kind presence; missing readings never become zero. No browser MQTT credential, telemetry write, persistent token/cache, agronomic severity or surveyed sensor position is introduced.

The optional freshness tint affects only the selected block's fill; the canonical selection outline and Spatial geometry are retained. CURRENT means observation age at or below the configured boundary; STALE is above it; NONE means absent; CLOCK_AHEAD means observed time ahead of the server. The panel's worst supplied age state drives the fill (clock issue, then stale, then current; none if no readings). Partial kind coverage stays explicit alongside the tint. This is a display policy, not sensor accuracy, an agronomic alarm or an operational SLA.

Optional public configuration keys are `telemetry.displayAgeSeconds` (default 300, allowed 1–86400) and `telemetry.pollSeconds` (default 30, allowed 5–300). Invalid settings fall back to defaults. Existing runtime configuration is preserved. Age uses server `generatedAt` plus monotonic visible-session elapsed time. Foreground polling pauses while hidden, invalidates pending requests and requires a fresh response on return. Selection changes cancel and clear prior values. Denial clears values and stops polling; 404 is unknown/inactive; an outage can show labelled same-block last-known values with no active tint. Route destruction removes timers/listeners/requests.

Run the AGENTS checks independently. Mock browser fixtures support `AGRO_TEST_PORT` for a separate preview port; run UI and graphics suites sequentially. `telemetry-live` is exclusively driven by Infrastructure's new owned generated drill, with a transient credential fixture and traces disabled. It starts a new loopback listener on a separately allocated port and serves built public assets with transient generated configuration. Only the new fixture realm/Gateway use the matching redirect/CORS origin; the listener closes in finally and never reuses an existing server/configuration. Use `scripts/build-public-image.ps1` for packaging: its allowlist supplies public defaults without copying the operator's `public/config.json`.

Named-device M2 frame/view/asset/memory acceptance, owner connected functional acceptance, offline Android capture/sync, English/French and REAL/production readiness remain open in the single Architecture completion checklist.
