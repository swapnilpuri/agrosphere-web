# Digital Twin geometry loading - 2026-10-28

An owner reported a blank-looking map with one spatial feature and a missing-selected-record geometry warning. Read-only existing local Gateway queries confirmed a mixture of integration estates: single block polygons, estates without geometry, and complete synthetic estates with 13 polygons (one estate, two divisions, ten blocks). Offline ellipsoid/no imagery is the configured default and does not prevent local GeoJSON polygons from rendering. No missing boundaries were invented and no business data or imagery-provider configuration was changed.

The component had an independent timing defect: selection could be evaluated before asynchronous geometry arrived. Completing a load updated only the feature count; it did not rerun selection navigation, leaving a stale warning or allowing the load's reset view to replace the selected camera target. A successful current-generation load now invalidates selection navigation, which reapplies the current selection and clears the warning when its boundary exists. Superseded loads still return undefined and do not trigger this update. Records without matching geometry continue to show the warning.

Validation passed: 32 unit/component tests including a deferred-load regression; lint, formatting, TypeScript, pinned API comparison and production build; two UI browser tests; one actual Cesium graphics/picking/teardown browser test; and two sequential real-Keycloak/Gateway live browser runs, one against a single-feature estate and one against a complete 13-feature estate. Live traces were disabled and credentials supplied privately through environment variables. The live test explicitly rejects a stale missing-geometry warning after selecting a block with geometry. A live screenshot was visually inspected and shows supplied polygons and block details, with no imagery as configured.

Independent Docker packaging passed as agrosphere-web:local-geometry-fix, image sha256:7e5bac9b84d1e6ad2976f1b62fd90dde3a46e1e66c58f0427d3a1a0140272e2e. This is a local build, not publication or production deployment. The existing Angular development server rebuilt and sent a reload to connected clients. Tests created no business records. No backend, private configuration, production or AEO changes were made for this fix. Software-WebGL checks are not reference-device performance acceptance; the separate M2 performance gate remains open.
